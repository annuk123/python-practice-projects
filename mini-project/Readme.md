
## My Python learning plan

I'll follow a structured curriculum rather than randomly jumping between topics.

## 01

Python fundamentals

Current stage

Variables, data types, input/output, operators, strings, type conversion, conditions, loops, and basic error handling.

Goal: Write small programs independently.

## 02

Collections and problem-solving

Lists, tuples, sets, dictionaries, indexing, slicing, membership, and nested data structures.

Goal: Store, organize, and manipulate information.

## 03

Functions and code organization

Defining functions, parameters, return values, scope, imports, modules, packages, and reusable code.

Goal: Break larger problems into smaller functions.

## 04

Intermediate Python

File handling, exceptions, comprehensions, working with paths, debugging, testing, object-oriented programming, and standard-library tools.

Goal: Build organized, reliable applications.

## 05

Advanced Python and practical development

Iterators, generators, decorators, context managers, type hints, more advanced object-oriented concepts, concurrency, performance, and application architecture.

Goal: Understand how to design and maintain larger programs.
